# Changelog

### Added
- Agent auto-detection with all 27 agents
- ImGui-style overlay menu with live toggles and sliders
- Handle hijack fallback for driverless operation

### Fixed
- ESP box flickering on fast-moving targets
- Silent aim angle snap detection edge case
